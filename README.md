# cma_public

Public documents for the **Crypto Market Analysis** (CmA) Android and iOS app.

The repository contains no application code and no market data — only
documents that must be reachable at a public URL, such as the privacy policy
linked from the Google Play listing.

- [PRIVACY.md](PRIVACY.md) — privacy policy

The app's data (`snapshot.json`, `profiles.json`) used to be published here.
Since 17 September 2026 it is served to the app by our own gateway instead:
the data providers' licence terms do not allow it to be redistributed as a
publicly downloadable file.
